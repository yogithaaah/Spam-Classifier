# 📩 SMS Spam Classifier

## Overview
This project is a **machine learning-based SMS spam detection system** using Python.  
It classifies messages into **Spam** or **Ham** using **TF-IDF features** and a **Support Vector Machine (SVM)**, providing accurate and interactive predictions. 💻✨

## Features
- ⚡ **Fast Training:** Trains quickly on the SMS Spam Collection Dataset (~5k messages)  
- 🎯 **High Accuracy:** Achieves ~98% accuracy in spam detection  
- 📝 **Interactive Prediction:** Input any SMS and get real-time classification  
- 📊 **Visualization:** Confusion matrix displayed with percentages for better insight  
- 🔧 **Reusable Model:** Trained model and vectorizer saved for quick inference
